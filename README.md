# University Network Design

### Computer Networks Course Project

A six-campus university network designed and simulated using **Cisco Packet Tracer**. The project focuses on building a scalable and structured network that supports communication between different university campuses.

### Key Features
- Six interconnected university campuses
- VLAN segmentation for students, faculty, administration, servers, and Wi-Fi
- OSPF and EIGRP routing protocols
- IP addressing and subnetting
- DHCP configuration
- Wireless network connectivity
- Network security configurations
- Packet transmission and connectivity testing

### Technologies Used
- Cisco Packet Tracer
- OSPF & EIGRP
- VLANs
- TCP/IP
- DHCP
- Cisco CLI

### How to Run
1. Install Cisco Packet Tracer.
2. Download the `University-Network.pkt` file.
3. Open the file in Cisco Packet Tracer.
4. Explore the network topology and device configurations.
5. Use ping or Simulation Mode to test network connectivity.
